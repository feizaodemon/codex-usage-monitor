## 背景

v1.9.1 发布后，社区提交了 3 个 PR：#6（已用/剩余切换）、#7（外观菜单与显示器选择）、#8（缺失额度窗口显示、按服务独立刷新、悬停说明、任务栏左侧固定）。#8 修复了只有每周额度的 Codex 账户被误显示为“剩余 100%”的问题，可靠性收益最大。三个 PR 两两冲突，且各有一个需要在合并前修正的问题。本地另有一份与 #8 重复、未能编译的半成品。
